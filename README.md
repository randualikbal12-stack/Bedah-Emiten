# Bedah Emiten

Aplikasi jurnal & analisis saham pribadi (BEI). Berjalan di HP sebagai aplikasi terpasang, data tersimpan di perangkat.

## Cara memasang lewat GitHub Pages
1. Di repositori ini: **Settings → Pages → Branch: main, folder: / (root) → Save**.
2. Tunggu 1–2 menit. Alamat aplikasi: `https://NAMA-AKUN.github.io/NAMA-REPO/`
3. Buka alamat itu di Chrome Android → menu ⋮ → **Instal aplikasi**.
4. Buka aplikasi → **Emiten tersimpan → Pulihkan dari cadangan** (jika punya cadangan lama).
5. **Pengaturan** → pilih penyedia AI → isi kunci → **Simpan & uji koneksi**.

## Memperbarui
Unggah file versi baru dengan nama yang sama (Add file → Upload files → Commit changes).
Buka aplikasi dua kali: versi baru aktif.

Data dan kunci API hanya tersimpan di HP, tidak ikut ke GitHub.
